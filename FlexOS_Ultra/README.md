# FlexOS Ultra — carpeta lista para Arduino IDE

Esta carpeta contiene el sketch P4 completo. No es necesario copiar archivos
sueltos ni juntarlos manualmente.

1. Descarga el repositorio o solamente esta carpeta conservando su nombre
   `FlexOS_Ultra`.
2. Abre `FlexOS_Ultra.ino` desde esta misma carpeta.
3. Selecciona la placa ESP32-P4 y la tabla `flexos_ultra_usb.csv` usada por el
   proyecto.
4. Compila y sube por USB.

No añadas `FlexOS_Pro.ino` ni `FlexOS_Ultra_S3.ino` a esta carpeta: pertenecen
a otras placas y Arduino IDE intentaría compilarlos junto con el sketch P4.
